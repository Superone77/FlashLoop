FlashLoop: Fast and Memory-Efficient Looped Transformers via Lazy Updates

Training-free inference for looped Transformers through lazy cross-loop updates.

Wanqi Yang1,2,3 Shiwei Liu1,2,3

1 Max Planck Institute for Intelligent Systems  ·  2 ELLIS Institute Tübingen  ·  3 Tübingen AI Center

Core Contributions

↻

Lazy Token Updates

Reuse converged states and recompute only the token positions that remain active.

⌁

Loop-Aware Attention

Focus attention work on important key columns predicted from the preceding loop.

▦

Compact KV Cache

Store a quantized base and low-bit cross-loop residuals instead of full per-loop KV states.

Inference Resource Trade-off

Parameter sharing reduces stored weights, while FlashLoop also targets the compute and KV-cache cost of repeated passes.

The motivation

Recurrent passes are full of lazy updates.

As recurrence proceeds, the next loop often changes only a small part of the previous one. The paper identifies three linked forms of cross-loop redundancy.

01 / TOKENS

Few states change substantially

Hidden-state and KV updates increasingly concentrate on a subset of token positions.

02 / ATTENTION

Important keys stay sparse

A small, predictable set of key columns dominates changes in attention output.

03 / MEMORY

Residuals compress better

Adjacent-loop KV differences have lower low-bit reconstruction error than full KV states.

The Method

Training-free inference via lazy updates

Core Insight

Early loops establish a dense state. In later loops, FlashLoop spends work where the recurrent state is still changing and reuses the rest.

STEP 01

Token-Sparse Updates

Reuse converged hidden and KV states. Recompute and store new states for active tokens only.

STEP 02

Sparse Attention

Select important keys using the previous loop's attention contributions, while retaining global probability mass to preserve scale.

STEP 03

KV-Residual Quantization

Store a quantized base state and low-bit residual updates instead of repeatedly storing complete KV states.

The optimized implementation gathers selected tokens and keys into compact buffers and fuses cache updates with quantization for GPU execution.

Key Takeaways

Training-free conversion improves looped inference without changing model weights.

Cross-loop redundancy lets FlashLoop reuse tokens, select attention columns, and store compact KV residuals.

Measured efficiency gains reach up to 1.64× end-to-end speedup and about 6× KV-cache reduction across the evaluated variants.
